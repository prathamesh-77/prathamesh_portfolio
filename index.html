My company projects are internal, so this is a small public project you can read and run. It uses synthetic data only, and it makes no claim about any workplace result.

Personal project · public on GitHub

Multi-team report consolidation

Built withPython, pandas, SQL, pytest

  1. 4 team files, 4 formats
  2. Map to one schema
  3. Validate, clean and log every change
  4. One report and weekly KPIs

Four teams send the same weekly progress report in different formats: different column names, date formats, delimiters and status wording. The pipeline maps each file to one schema, drops or flags bad rows, and records every decision in a validation log, then writes one consolidated report and a weekly summary.

  • Python: per-team configuration, loud failure when a template changes, and 12 passing tests.
  • SQL: three queries in portable SQL (tested on SQLite) using CTEs, LAG, ROW_NUMBER and RANK.
  • Outputs: consolidated CSV and Excel workbook, weekly summary, and a validation log with source row numbers.
